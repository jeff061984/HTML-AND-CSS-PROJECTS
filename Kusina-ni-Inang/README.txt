KUSINA NI INANG

Files:
- index.html: website content and recipe details
- style.css: website colors, image sizes, layout, and responsive styling

How to view:
1. Extract the ZIP.
2. Open the Kusina-ni-Inang folder in VS Code.
3. Open index.html in your browser, or use Live Server.

The page includes Home, Recipes, an original About section, food images, and responsive styling.
The recipe images use online Unsplash image URLs, so an internet connection is needed to load them.
Before submitting, compare the website with your instructor's tutorial requirements and personalize the About section.
